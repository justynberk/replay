# Changelog

## 0.1.0-beta.1

First browser-based local release candidate.

- Screen, camera and audio recording with local recovery drafts.
- Reversible editing, captions, camera layouts, zoom regions and rendered exports.
- Local library, review, isolated viewer links and watch-page analytics.
- Repo-level installation and one-command startup with dependency and port checks.
- Local production frontend, optional AI configuration and backup instructions.

This is a prerelease. Hosted sharing and native desktop applications are outside its scope. See the README for verification limits.
